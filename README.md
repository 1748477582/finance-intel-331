## 它想解决的问题

财经信息的主要矛盾不是不够多，是**噪音太多**，而且噪音伪装成信号。

- 热搜第一的往往是情绪最强、信息量最低的那条
- 央行数据发布时无人问津，自媒体解读时全网刷屏
- 看了一整年财经号，说不出哪条判断是对的，因为从来没记录过

这个工具做三件事：**给信息打分并说明打分依据**、**把宏观数字翻译成对你个人的影响**、**记录你的判断并到期提醒你回来复盘**。

它不告诉你买什么。它帮你分清什么值得花时间。

## 八大模块

| 模块 | 干什么 |
|---|---|
| **今日信号** | 当日情报总览、信号雷达、资金流向盘面、慢信号 |
| **情报库** | 粘标题选信源，实时算信号分。可切「事件聚合」视图做多源比对 |
| **数据** | 指标趋势、关联密度、产业链上中下游结构映射 |
| **分析·市场热点** | 事件影响分析：传导链、三情景、监控触发、证伪条件 |
| **分析·板块热度** | 双轨评分（信息×行情）、背离检测、催化时间线 |
| **分析·舆情追踪** | 多平台舆情汇总，每条必带来源链接，正负中分类统计 |
| **我的·决策复盘** | 记判断 → 到期提醒 → 填结果 → 看命中率 |
| **我的·设置** | 数据导出/导入/清空 |

### 信号分是怎么算的

```
信源权重 + 信息增量 + 多源验证 8 + 慢信号 10 − 已上热搜 15
```

| 项 | 取值 |
|---|---|
| 信源权重 | 官方一级 40 · 权威媒体 28 · 机构研究 20 · 自媒体 8 |
| 信息增量 | 硬数据 25 · 政策原文 20 · 分析观点 10 · 纯情绪 0 |

钳制在 0–100。**≥65 强信号 / 40–64 可参考 / <40 噪音。**

每条情报右下角有个「i」，点开显示这条的完整算式。**不做黑箱打分**——你能复算，才能决定信不信。

热搜倒扣 15 分是刻意的：一件事到了热搜，说明信息已经被充分定价，此时再行动通常是最差的时机。

### 多源比对

同一事件录多条，切到「事件聚合」视图，系统会检查不同信源对资金流向的判断是否一致。**不一致就整组标红**，并区分两种情况：官方口径 vs 自媒体口径打架（明说自媒体在放大情绪），还是同层级的不同解读（建议回原文核对）。

预置数据里有现成的一组：「北京楼市限购松绑」，住建委原文判「钱换地方」（53 分），自媒体版《全面放开！楼市要暴涨》判「钱变多」（0 分）。

### 每日晨报

顶栏一键生成，按 1/7/30 天汇总成纯文本，可复制。

和普通新闻摘要的区别：它**同时列出被过滤掉的噪音和过滤原因**。知道什么不值得看，比多看几条更有价值。

## 数据与隐私

**你录入的所有内容都只存在你自己的浏览器里，不经过任何服务器，本仓库和 GitHub 都收不到。**

- 存储用浏览器本地存储，上限约 5MB，够存几千条纯文本
- 首屏就有「导出 JSON」和「导入恢复」，不藏在设置里
- 记账/统计类数据可导出 CSV
- 清空数据需二次确认
- 数据攒到 30 条会提示你导出备份

因为数据按网址隔离，**换浏览器或换设备不会同步**，靠导出导入迁移。这是刻意的取舍：不做账号体系，就不存在数据泄露的可能。

## 合规声明

本工具**不提供任何投资建议，不推荐任何标的，不承诺任何收益**。

- 信号分只反映「这条信息值不值得花时间」，**不代表涨跌方向**
- 产业链模块只做客观的上下游结构映射，板块归类到申万行业名为止，**不含任何股票代码、基金代码或标的名称**
- 决策复盘的目的是「看清自己在哪类判断上会稳定犯错」，不是提高收益
- 生成的晨报文本自带免责声明，复制出去也带着

自动化检查里有专门的合规断言：扫描全文不得出现投顾类措辞，产业链和晨报输出不得出现六位股票代码。

## 技术约束

单文件 HTML，**所有 CSS、JS、图标全部内联，零外部依赖**。

这不是偷懒，是吃过亏：引用了 CDN 的页面，一旦用户只保存了 HTML，或者 CDN 挂了、被墙了，功能全废。所以：

- 图表全部手写内联 SVG，不用任何图表库
- 图标用内联 SVG path，**不用 emoji 当图标**（跨平台渲染不一致）
- 字体用系统字体栈
- 断网也能正常用

代码按**数据层 / 渲染层**分离。`<script>` 开头到「渲染层」注释之间约 366 行是纯逻辑，零 DOM 依赖，可整段复制到微信小程序，只需把浏览器存储换成 `wx.getStorageSync`。

## 本地开发

```bash
git clone https://github.com/1748477582/finance-intel-331.git
cd finance-intel-331
npm test          # 跑全部检查，不需要装任何依赖
```

| 命令 | 内容 |
|---|---|
| `npm run test:core` | 134 项数据层断言：信号分、流向、领域、产业链、事件分歧、晨报、存储迁移、复盘、XSS |
| `npm run test:lint` | 33 项静态检查：零外链、无 emoji、引用完整性、移动端适配、数据闭环、合规措辞、体积 |

测试脚本会自己从 `index.html` 里正则抽出内联脚本、按注释切出数据层、在 Node 里 mock 浏览器存储后执行。**改完 HTML 直接跑，不需要额外构建。**

每次推送到 `main` 会自动跑这 167 项检查，**全过才部署**。挂了就不上线。
