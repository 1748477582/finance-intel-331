# 财富情报网 V4 · 迭代说明

## v4.0.0（2026-08-12）

### 新增：分析中心（第五个主 Tab）
三个子模块，均遵循「先结构化、再判断」的方法论：

1. **市场热点事件分析**
   - 事件身份核验（类型、状态、来源、日期）
   - 传导链：直接影响 → 二阶传导 → 高阶影响
   - 三情景：基准 / 上行 / 下行
   - 监控触发信号 + 证伪条件
   - 数据存 localStorage（wb_events），预置 2 条示例

2. **板块热度双轨评分**
   - 信息热度 1-5 + 行情热度 1-5，综合分 = 行情×0.55 + 信息×0.45
   - 四种背离状态：强趋势共振 / 纯资金驱动 / 题材未启动 / 低关注
   - 催化时间线（多空方向标记）、观察信号、风险提示
   - 数据存 localStorage（wb_sectors），预置 2 条示例

3. **舆情追踪与溯源**
   - 每条舆情必须填写原帖链接（前端校验）
   - 支持微博/知乎/即刻/脉脉/B站/新闻等平台标记
   - 正/负/中三分类统计（数量+占比）
   - 先总结后详情的展示结构
   - 数据存 localStorage（wb_sentiment），预置 1 条示例

### 视觉：暗夜运维深色主题
- 近黑蓝底（#08090f / #0c0e14）、薄荷绿主强调色（#6ee7b7）
- 等宽字体标签、章节编号、1px 描边、无阴影
- 资金流向颜色语义保持（红=钱变多/看多，绿=钱变少/看空）
- 覆盖全部硬编码浅色，含详情页、弹窗、设置等

## 〇、V3 本轮新增（三件全做完）

| 功能 | 落位 | 说明 |
|---|---|---|
| **产业链映射器** | 新增第 5 个 Tab「产业链」 | 4 条链 × 上中下游三层 × 55 个环节 |
| **多源比对与解读分歧** | 情报流顶部「列表 / 事件聚合」切换 | 同一事件多信源并排，流向判断打架时标红 |
| **每日晨报生成** | 顶栏金色「生成晨报」按钮 | 一键拼出可复制文本，含免责尾巴 |

导航仍是 5 个 Tab，没有平铺成一堆入口——新功能按层级插进了已有结构里。

### 1. 产业链映射器

四条链，每条含关键词表 / 上中下游三层 / 板块归类 / 一句避坑提示：

| 链 | 板块归类 | 提示要点 |
|---|---|---|
| AI 算力硬件 | 电子·通信设备·计算机 | 公募持仓已从纯硬件往应用端迁移，硬件端拥挤度要留意 |
| 新能源车 | 电力设备·汽车·有色 | 补贴影响下游节奏，上游看全球供给，别把政策利好当销量 |
| 地产链 | 房地产·建材·家电 | 政策底 ≠ 市场底；后周期家电家居通常滞后 6–12 个月 |
| 黄金与贵金属 | 有色·商业贸易 | 央行增持是储备逻辑，和短期金价的交易逻辑不是一回事 |

录情报时自动匹配产业链（`guessChains`），产业链页能反查「这条链最近有哪些情报」。
支持自己加链、改避坑提示、删链。

**合规处理：只做客观上下游结构映射，板块归类到申万行业名为止，不给任何基金代码、股票代码、标的名称。** 测试里有一条专门断言扫全文无 6/0/3 开头的六位数字。

### 2. 多源比对与解读分歧

情报流右上角切「事件聚合」，按 `event` 字段把同一件事的多条情报收拢：

- 组内按信号分降序，官方口径自然排最上
- 检测到组内 `flow` 判断不止一种 → 整组标红，顶部弹「解读分歧」提示条
- 分歧组自动排到列表最前
- 文案会区分两种情况：官方 vs 自媒体口径不一致 → 明说「自媒体版本大概率在放大情绪」；同层级不同解读 → 建议回原文核对

预置数据里做了一组现成演示：**「北京楼市限购松绑」** 官方住建委版（政策原文，判 `钱换地方`，53 分）对上自媒体版（「全面放开暴涨」，纯情绪 + 热搜，判 `钱变多`，0 分）——同一件事，两种流向，直接标红。

另两组「7月外储与黄金储备」「AI算力硬件景气度」是官方/机构同向，不算分歧，用来证明不会误报。

### 3. 每日晨报

按 1/7/30 天区间汇总，输出纯文本：

```
【情报晨报】2026年8月10日
统计区间：2026-08-04 至 2026-08-10（7 天）

■ 资金流向格局：总量平稳，结构在动
   钱变多 3 条（37%）· 钱变少 0 条（0%）· 钱换地方 5 条（63%）
   计入 8 条，已过滤噪音 2 条

■ 强信号 4 条
1. [73分] 7月末外汇储备34188亿美元…
    来源：国家外汇管理局（官方一级）｜钱变多
    解读：…

■ 解读分歧提醒 1 组
   · 「北京楼市限购松绑」出现 钱换地方／钱变多 两种以上判断

■ 慢信号轨道 1 条（短期不震动，长期最深刻）
■ 已过滤噪音 2 条
   · 牛市已来！这波满仓干…（自媒体信源、无信息增量、已上热搜）
———
本晨报由个人情报库自动汇总，信号分只反映信息价值，不代表涨跌方向，不构成任何投资建议。
```

噪音条目会标注被过滤的原因，这是这份晨报和普通「新闻摘要」的区别——**它同时告诉你哪些东西不值得看，以及为什么**。一键复制，可直接发号。

## 二、五个模块

**1. 情报流（信号/噪音引擎 + 多源比对）**
粘标题 → 选信源和信息增量 → 实时看到分数怎么算出来的。
公式：`信源权重 + 信息增量 + 多源验证8 + 慢信号10 − 热搜15`，钳制 0–100。
分级：≥65 强信号 / 40–64 可参考 / <40 噪音。
每条右下角「i」按钮点开显示完整算式——**不做黑箱打分**，这是可信度的来源。
右上角可切「事件聚合」进多源比对视图。

**2. 影响翻译（含资金流向盘面）**
上半是盘面，按情报库实时汇总，且**排除噪音后再统计**。
下半是宏观指标个人翻译层，预置 M2 / 外储 / 进出口 / CPI-PPI 四条。

**3. 产业链**（V3 新增）
4 条链的上中下游结构图 + 板块归类 + 避坑提示 + 关联情报反查。

**4. 关注雷达**
6 个领域的资金流向构成条 + 信号强度横向柱状图（内联 SVG 手写）。
底部是慢信号轨道单独陈列。

**5. 决策复盘**
记判断 → 选 7/30/90 天验证期 → 到期进「今天要处理」并标红 → 填结果和复盘笔记。
命中率环形图，部分正确按半分计。

## 四、合规处理

- 页面底部固定免责声明：不提供买卖建议、不承诺收益
- 明确标注「信号分反映信息值不值得花时间，**不代表涨跌方向**」
- 产业链页明示「**不含任何标的推荐**」，板块只到申万行业名
- 晨报文本自带免责尾巴，复制出去也带着
- 复盘模块文案刻意写成「看清自己在哪类判断上会稳定犯错」，而非「提高收益」
- 所有数据只在本机浏览器，不上传

## 六、迁移微信小程序的要点

代码已按数据层/渲染层分离，`<script>` 开头到「渲染层」注释之间（约 366 行）是纯逻辑，**零 DOM 依赖，可整段复制进小程序**：

- `SOURCES` / `INC` / `FLOW` / `KW_FLOW` / `DEF_FIELDS` / `DEF_CHAINS` — 常量表
- `score()` — 打分，纯函数
- `guessFlow()` / `guessFields()` / `guessChains()` — 自动分类，纯函数
- `groupByEvent()` / `divergeText()` — 事件聚合与分歧检测，纯函数
- `genBrief()` — 晨报生成，返回纯字符串，小程序里直接 `wx.setClipboardData`
- `todayStr()` / `shift()` / `diffDays()` — 日期工具

需要替换的只有存储层两个函数：
`localStorage.getItem/setItem` → `wx.getStorageSync/setStorageSync`

四张表 `intel` / `decisions` / `fields` / `chains` 结构扁平，字段无嵌套（`chains[].tiers` 是唯一一层数组嵌套），可直接映射到云开发数据库集合。
